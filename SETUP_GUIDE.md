## Quick Start

1. Upload the contents of the `pwa/` folder to your web server root
2. Upload `assetlinks.json` to `/.well-known/assetlinks.json`
3. Add the manifest link to your HTML `<head>`:

```html
<link rel="manifest" href="/manifest.json">
```

4. Register the service worker in your HTML:

```html
<script>
if ('serviceWorker' in navigator) {
    navigator.serviceWorker.register('/sw.js');
}
</script>
```
